# 小康 TUI - 业务与代码排障智能终端 (`xhang`)

面向客服与二线技术支持人员的 **代码与业务排障 TUI 智能助手**（基于 Harness + MCP 混合工具架构与企业模型安全网关）。

---

## 🚀 一键安装与全局启动

在任何 **PowerShell** 或 **CMD** 终端窗口中：

### 1. 全局注册指令（首次只需执行一次）
```bash
cd D:\web_pro\xkang-tui
npm install
npm run build
npm link
```

### 2. 任意目录下直接输入 `xhang` 打开 TUI 客户端
```powershell
# 在任意项目目录或排障工作区直接输入：
xhang

# 或者传入自定义服务端地址与代码库路径：
xhang -s http://localhost:8090 -t tok_dev_001
```

*(同时也保留了 `xkang` 别名)*

## 🔒 三重安全防护体系

1. **工作区路径安全沙箱 (`PathSandbox`)**：
   - 所有文件写入与编辑操作强制锁定在当前 `repoPath` 目录树内，禁止 `../` 越界与跨盘符篡改。
2. **命令风险治理引擎 (`validateCommandPolicy`)**：
   - 优先通过正则拦截破坏性删除（`rm -rf`、`Remove-Item -Recurse`）、系统篡改（`reg add`、`net user`）、提权（`RunAs`）与网络外联命令；
   - 严格限定仅放行安全排障白名单命令（`git status/log/diff`、`mvn test`、`npm test`、`node/java -v`、`Get-Process` 等）；
   - 执行前自动探测 `powershell.exe` 可用性，企业 AppLocker / WDAC 管控环境下优雅降级。
3. **TUI 交互式操作审批门 (`ApprovalGate`)**：
   - 执行写文件、改代码或跑命令前，Promise 暂停 Agent 循环，TUI 弹出高亮审批卡片展示操作详情与 Diff；
   - 员工手动键盘确认后方可执行；员工拒绝时文件与系统零变更，模型自动接收拒绝反馈继续会话。
4. **统一 128k 上下文防溢出机制**：
   - 强制全局锁定 128k 上下文窗口与 96k 动态压缩阈值，严防超出模型处理边界。
