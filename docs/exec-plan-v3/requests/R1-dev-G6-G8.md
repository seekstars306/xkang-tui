## 六、盲评排期（G8）

摸底跑完后需要你盲评 **30～40 条**输出，每条约 **5 分钟**，合计约 **3 小时**。

盲评包会把候选答案打乱顺序、隐去配置名和生成时间，你只需要按四栏（参考答案要点 / 禁止断言 / 核心诉求 / 适用范围）逐条打"符合 / 否决 / 修改"。**这是全流程最紧的一环，希望提前定时间。**

一个重要前提：盲评的题目里会有真实工单（含客户姓名、电话、单号、金额，**不脱敏**，因为那正是要核对的数据）。数据只放在本机不进代码仓库的目录里，不会进提交或对外报告。
