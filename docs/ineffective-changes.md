## 避免重走的路

1. 不因增加轮数、加提示、加台账或复核名词就预期质量提高。先定位关键证据未取到、取到但理解错、正确初稿在发布中损耗中的哪一层。
2. 硬门禁前必须保证不把唯一证据挤掉、不因局部问题整篇吞稿、不把格式/引文通过当业务事实。
3. 后续实验按最小单机制、固定输入/版本/预算、明确人工金标准分层进行；未达目标回退，负例和原始记录不能清掉救分。
4. 当前有效业务逻辑保留在a905e74回退基线上；本次清理仅移除孤立诊断脚本及本地重复产物，不默认新增质量改造或切生产模型。

相关实验源码保存在Git历史和本地原始证据；清理范围与恢复方式见[清理记录](<docs/cleanup-20261102.md>)。
