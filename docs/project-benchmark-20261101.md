# 五模型中型项目构建测试：FlowQueue

## 结论

**本轮只有Sonnet 5.5完成工程并通过全部验收。** 它写了8个非空TypeScript模块（336行、约16.7KB），4轮模型请求、15次工具操作，严格构建通过，公开12/12、隐藏74/74。独立只读复核确认入口实际使用6个业务模块，未发现硬编码隐藏用例名称；权限、幂等、日志恢复及租约路径未发现已证实错漏。

这是中型复杂业务服务的压缩切片，不是单函数题，也不是完整生产HTTP服务、前端或数据库部署。单入口App.handle组装多个模块，复杂度来自多状态机和跨模块不变量，而非文件数量。

## 项目与固定条件

实现任务创建、审批/驳回/取消、权限及多租户、请求幂等、乐观版本、依赖任务调度、租约完成、到期回收与重试上限、事件日志恢复、任务和审计查询。详细接口、字段和错误优先级见[完整需求](<eval_run/project-20261101/SPEC.md>)。

- 同一初始占位工程、完整题面和平台契约；可信TypeScript5.9.3执行strict构建。
- 模型工具仅list_files/read_file/write_file/build/test_public；禁止任意shell、外部依赖、改平台/测试或编译选项。隐藏用例不反馈模型。
- 每模型25分钟有效工作时间、20次模型请求、80次工具操作，先到者停；每请求完整240秒、输出32000 token。第20轮工具可以执行，禁止第21请求。
- 全局2请求、每模型1请求；全局排队不计25分钟，请求和工具执行计入。同步构建/公开测试可能延后其它HTTP超时回调，这是协作式时限，不宣称绝对抢占式硬保证。
- 文件读最多2000字符，可offset续读；完整SPEC和平台契约直接包含在首条用户消息。公开测试共32,214字符，模型自行选择是否分页阅读。
- DS/Kimi/GLM走原本机agent2api/max；Gemini原cpa/high，Sonnet linke2/high，经现有Clash7890，HTTPS验证证书。不同路由/思考档位及隐藏权重未统一认证。
- 固定12公开和74隐藏场景，12类各至少6例，含2个1000任务/5000操作性能场景；期望由独立作者按需求写出。
- 参考严格构建、12/12公开、74/74隐藏全部通过后冻结。最初10秒性能时限让参考两例中断；在任何模型请求前统一调为性能60秒并通过，再冻结，失败记录保留。

## 隔离与恢复

trusted TypeScript只读虚拟项目及固定编译器lib，禁止外部import、动态import、三斜线引用和越界路径。实际模型JS只在QuickJS-WASM内运行，虚拟require只加载项目模块，不给宿主process、网络、Node模块或文件能力。期望checks留在宿主，不传给模型代码。

每次rebuild结束旧QuickJS，再建立新runtime/module缓存，只搬运序列化journal和可信时钟状态，避免全局变量/引用缓存伪恢复。store读写复制JSON，覆盖append失败不改state/计数/幂等，以及恢复后继续写入和重放响应；这是EventStore契约恢复，不是实际磁盘耐久性或跨进程数据库并发。

guest普通场景10秒、性能60秒、256MiB堆/2MiB栈/周期interrupt；底层WASM有宿主运行支持，宿主编译/转换没有OS级总RSS/硬时限保证，不宣称绝对安全或精确指令fuel。冻结前已修第20请求工具误拒及模板替换污染源码两项缺陷，再通过工具自测/参考后启动。
